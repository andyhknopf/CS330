**TSP using best first** Implement TSP problem using best first algorithm (so it will be backtracking, branch-and-bound, and best-first). It is recommended to implement in steps (so you are dealing with one subproblem at a time): - first implement backtracking (will solve 5-6 cities, but will take seconds for bigger sizes) - add bound (see below) and add pruning logic - restructure code to use best first Notes: - since you are looking for a cycle, the start/finish city is not important. Therefore we assume that start and finish city is always index 0. - thus - solution is a permutation of the remaining cities (1,2,...,n-1) with 0 at the beginning and end. - use recursive permutation generation from notes (see assignment problem) The **bound**. As discussed in class, solution of the relaxed problem (where we ignore some of the constraints of the original problem) is a lower bound on the solution of the original problem. Let's assume we are in the middle of the search and we have a partial path (0->1->2->3) and remaining cities are 4,5,6. **Original problem**: 1. find 4 directed edges 2. each of the remaining cities 4,5,6 has an incoming edge FROM one of the cities 3,4,5,6 (current city 3 is included because it is the last city in the current path and it can be connected to one of the remaining cities) 3. city 0 has an incoming edge FROM one of the cities 4,5,6 (current city 3 is **excluded** because 3->0 will conclude the cycle and cities 4,5,6 will not be visited) 4. each of the remaining cities 4,5,6 has an outgoing edge TO one of the cities 0,4,5,6 (city 0 is included) 5. city 3 has an outgoing edge TO one of the cities 4,5,6 (last city 0 is excluded because 3->0 will conclude the cycle and cities 4,5,6 will not be visited) 6. minimize the total cost of the 4 edges. Notice how constraints 2-5) enforce that the remaining 4 edges have to complete a cycle, and that is what makes makes TSP hard. **Relaxed problem**: drop constraints 4) and 5): 1. find 4 directed edges 2. each of the remaining cities 4,5,6 has an incoming edge FROM one of the cities 3,4,5,6 (current city 3 is included because it is the last city in the current path and it can be connected to one of the remaining cities) 3. city 0 has an incoming edge FROM one of the cities 4,5,6 (current city 3 is **excluded** because 3->0 will conclude the cycle and cities 4,5,6 will not be visited) 4. - 5. - 6. minimize the total cost of the 4 edges. Notice that the relaxed problem is trivial to solve: - find the shortest path to 4 from 3,5,6 (minimum of 3 edges) - find the shortest path to 5 from 3,4,6 (minimum of 3 edges) - find the shortest path to 6 from 3,4,5 (minimum of 3 edges) - find the shortest path to 0 from 4,5,6 (minimum of 3 edges) - add these 4 minimums together to get the solution of the relaxed problem.
