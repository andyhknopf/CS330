subarray within a one-dimensional array of numbers which has the largest sum.

{
    int size = 0;
    std::sscanf(argv[1],"%i",&size);  // problem size

    int num_tests = 0;
    std::sscanf(argv[2],"%i",&num_tests);  // number of experiments

    // create array size n with values [-n/3,2n/3] !!!!!!!!!!!!!!!!!!!!!!!!!
    int *a = new int[ size ];
    for (int i = 0; i < size; ++i) { 
        a[i] = i - size/3;
    }

    // C++11 RNG
    std::random_device rd;
    std::mt19937 gen( rd() ); // random engine

    for ( int experiment =0; experiment < num_tests; ++experiment ) {
        std::shuffle( a, a+size, gen ); // C++11

        // Kadane's algorithm starts here
        int max_so_far = a[0], max_ending_here = a[0];

        for (int i = 0; i < size; ++i)
        {
            max_ending_here = max_ending_here + a[i];
            if (max_so_far < max_ending_here)
                max_so_far = max_ending_here;

            if (max_ending_here < 0)
                max_ending_here = 0;
        }
        // Kadane's algorithm ends here

        std::cout << max_so_far << " "; // solution
    }
    delete [] a;
}

To empirically analyze the behavior of the maximum subarray sum, we execute a series of controlled experiments across varying problem sizes $N$. The execution pipeline for a single problem size $N$ is structured as follows:

\begin{enumerate}
    \item \textbf{Array Initialization:} An array of size $N$ is allocated and populated deterministically with sequential integers in the range $\left[ -\lfloor N/3 \rfloor, \lfloor 2N/3 \rfloor \right]$. This ensures that the elements have a net-positive bias but contain a significant proportion of negative values to prevent trivial solutions.
    \item \textbf{Randomization:} A C++11 Mersenne Twister pseudo-random number generator (\texttt{std::mt19937}), seeded via \texttt{std::random_device}, is utilized alongside \texttt{std::shuffle} to randomly permute the elements of the array.
    \item \texttt{Computation:} Kadane's algorithm is executed on the shuffled array to find the maximum contiguous subarray sum in $\mathcal{O}(N)$ time.
\end{enumerate}

\subsection{Data Aggregation and Curve Fitting}
To eliminate statistical noise generated by the random shuffling, the experiment is replicated $T = 200$ times for each problem size $N$. Let $M_{N, t}$ be the maximum subarray sum obtained during the $t$-th test for size $N$. The empirical expected maximum sum $\bar{M}_N$ is calculated as the arithmetic mean:
\begin{equation}
\bar{M}_N = \frac{1}{T} \sum_{t=1}^{T} M_{N, t}
\end{equation}
We vary $N$ from $1000$ to $20000$ in steps of $1000$. The resulting data pairs $(N, \bar{M}_N)$ are plotted and fitted against a mathematical model using a least-squares regression.
