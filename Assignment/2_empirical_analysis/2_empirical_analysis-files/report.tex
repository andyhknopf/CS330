\section{Introduction \& Problem Statement}
The Maximum Subarray Problem isolates a contiguous subarray within a one-dimensional sequence of numbers $A = [a_1, a_2, \dots, a_N]$ maximizing the cumulative sum value:
\begin{equation}
M = \max_{1 \le i \le j \le N} \sum_{k=i}^{j} a_k
\end{equation}
This study models the expected maximum subarray sum as a random variable to observe its asymptotic behavior as a function of the input array length $N$.

\section{Experimental Setup}
The testing framework operates directly inside a configured sequence environment:
\begin{enumerate}
\item \textbf{Initialization:} An array of size $N$ is filled sequentially where $a[i] = i - \lfloor N/3 \rfloor$.
\item \textbf{Randomization:} Element configurations are fully permuted using \texttt{std::shuffle} driven by a \texttt{std::mt19937} engine.
\item \textbf{Execution:} Kadane's algorithm executes across $T = 200$ randomized iterations per problem size $N$ to capture the average behavior.
\end{enumerate}
